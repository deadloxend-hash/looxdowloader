Frequently asked questions

Why is my link not working?

Make sure the link is correct, the post is public, and the platform's service is available through the configured backend.

Why is the thumbnail missing?

The backend must return a thumbnail URL. Some posts or API responses do not include thumbnail or creator information.

Does LOOX host my videos?

This page displays media URLs returned by the configured backend. It does not independently store or host the original media.
