FAQ

Why is downloading not working yet?

The current backend only validates Instagram URLs and returns a 501 response. Media extraction must be implemented on the server first.

Can I use private post links?

No. This page is intended for public links, and it cannot bypass private accounts or access controls.

Is Loox affiliated with Instagram?

No. Loox is an independent project and is not affiliated with Instagram or Meta.
